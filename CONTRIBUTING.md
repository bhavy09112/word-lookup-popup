# Contributing

Thanks for contributing.

## Development Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Guidelines

- Keep changes focused and small.
- Test lookup behavior manually on Windows before submitting.
- Update `README.md` if behavior or setup steps change.

## Pull Requests

- Describe what changed and why.
- Include any manual test notes (hotkeys used, apps tested).
